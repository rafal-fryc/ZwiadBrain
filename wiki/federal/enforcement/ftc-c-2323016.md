## Summary

The FTC charged Illusory Systems, Inc. (operator of the Nomad cryptocurrency bridge) with unfair security practices and deceptive security representations after a August 2022 hack drained approximately $186 million in user assets. Despite marketing its bridge as 'secure... period,' the company deployed inadequately tested code, lacked an incident response plan, and had no circuit breakers to halt an ongoing attack. The matter resolved in a 10-year consent order requiring a mandated information security program, biennial third-party assessments, and return of approximately $37.5 million in recovered assets to users.

## Background

Nomad operated a cross-chain cryptocurrency bridge that enabled users to transfer digital assets across blockchains. It marketed the bridge with prominent security-first claims while failing to implement basic secure coding practices, maintain adequate security staffing, or establish any incident response capabilities. In June 2022, Nomad deployed code containing a critical vulnerability; on August 1, 2022, hackers exploited it and drained nearly all assets in the bridge within hours, causing users to lose more than $100 million.

## Allegations

The FTC alleged two counts: (1) unfair security practices — Nomad failed to employ reasonable and appropriate software development practices including adequate code testing, incident response planning, vulnerability reporting, security staffing, transaction monitoring, and circuit breakers; and (2) security misrepresentations — Nomad falsely represented, expressly or by implication, that it implemented secure software development practices, in violation of FTC Act Section 5(a).

## Outcome

A 10-year consent order was issued requiring Nomad to: refrain from misrepresenting its security practices; establish and maintain a comprehensive information security program; obtain biennial independent third-party security assessments; have its CEO submit annual certifications of compliance; return approximately $37.5 million in recovered assets to affected users via bounty, recovery bridge, or court-ordered process with 11 months of website notice; and maintain five years of specified compliance records.

## Significance

This action signals that the FTC will hold cryptocurrency infrastructure operators to the same data-security standards applied to traditional financial services — including affirmative obligations around secure development lifecycle, incident response planning, and circuit-breaker controls — and that marketing claims about security create enforceable obligations regardless of the asset class involved.
