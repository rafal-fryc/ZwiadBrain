## Summary

The FTC charged Oracle Corporation with deceiving consumers by claiming that updating Java SE would provide the latest security improvements, while the update process left older, vulnerable versions of Java installed on users' computers. Oracle had known since 2011 that its update mechanism was failing to remove insecure older versions and that malware was actively exploiting them, yet never disclosed this to consumers. The matter resulted in a 20-year consent order requiring Oracle to stop misrepresenting the security of its software and to notify affected consumers.

## Background

Oracle distributed Java SE to over 850 million personal computers. During updates, it displayed screens telling consumers they would receive the latest security improvements, but the update process only removed the most recent prior version, leaving older insecure iterations installed. Oracle knew by 2011 that its update mechanism was inadequate and that malware was successfully exploiting already-patched vulnerabilities in older Java versions remaining on users' machines.

## Allegations

The FTC alleged one count: that Oracle misrepresented to consumers that updating Java SE would ensure their computers had the latest security improvements, while failing to disclose that older, insecure versions of Java SE would remain installed, leaving consumers unknowingly exposed to exploit kits capable of stealing passwords and sensitive personal information.

## Outcome

Oracle entered into a 20-year consent order (Docket C-4571) prohibiting misrepresentations about the privacy or security of its covered software. Oracle was required to clearly disclose the presence of older installed Java SE versions during any future installation or update, warn of associated security risks, provide uninstall instructions, and notify affected consumers through multiple channels including website, security bulletins, social media, and free uninstall tools.

## Significance

The action established that deceptive security claims about software update practices — where a company knowingly allows consumers to believe they are protected while leaving them vulnerable — constitute an unfair or deceptive act under FTC Act Section 5, even absent a direct data breach. It also set a precedent for affirmative disclosure and consumer notification obligations as remedies in software security cases.
