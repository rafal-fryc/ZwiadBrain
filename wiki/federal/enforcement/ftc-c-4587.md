## Summary

The FTC charged ASUSTeK Computer, Inc. with making deceptive security representations about its consumer routers and cloud features while failing to implement basic security protections. Vulnerabilities in the routers — including authentication bypass and default settings exposing USB storage to the public internet — allowed hackers to access thousands of consumers' files and leak over 3,000 AiCloud login credentials. The matter resolved as a 20-year consent order requiring a comprehensive security program and biennial third-party assessments.

## Developments

- 2016-07-15 — Consent order issued requiring ASUSTeK to implement a 20-year security program and biennial third-party assessments after routers with deceptively marketed security features exposed thousands of consumers' data to hackers. — [source](https://www.ftc.gov/legal-library/browse/cases-proceedings/142-3156-asustek-computer-inc-matter)

## Background

ASUSTeK sold consumer routers with AiCloud and AiDisk cloud features, marketing them as secure platforms for storing sensitive personal information. Despite receiving researcher vulnerability reports beginning mid-2013, ASUS delayed notifying consumers and taking corrective action for months. By early 2014, hackers had exploited the flaws to access consumers' USB storage devices and publicly posted login credentials for over 3,000 AiCloud accounts.

## Allegations

The FTC alleged five counts: (1) misrepresentations that routers took reasonable steps to protect local networks; (2) misrepresentations that AiCloud was a secure 'private personal cloud'; (3) misrepresentations that AiDisk safely secured consumer data; (4) misrepresentations that the firmware upgrade tool accurately reported whether routers were running current firmware; and (5) unfair security practices for failing to take reasonable steps to secure router software while offering devices for network protection and sensitive data access.

## Outcome

ASUS agreed to a 20-year consent order (Docket C-4587, issued 2016-07-15) prohibiting misrepresentations about device security, requiring a comprehensive documented security program, mandating biennial independent third-party security assessments by CSSLP- or CISSP-credentialed professionals for 20 years, and requiring consumer notification of software updates and security flaws with a registration mechanism during device setup.

## Significance

This order established that router manufacturers who market security features bear an affirmative obligation to actually implement reasonable security — and that delayed response to known vulnerabilities, combined with default-insecure settings, constitutes an unfair practice under Section 5. The 20-year assessment requirement with credentialed third-party auditors set a rigorous precedent for IoT/connected-device security consent orders.
