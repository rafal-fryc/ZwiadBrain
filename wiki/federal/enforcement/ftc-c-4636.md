## Summary

The FTC charged Lenovo with deceptive and unfair practices for preinstalling VisualDiscovery adware on over 750,000 consumer laptops without adequate disclosure. The software acted as a man-in-the-middle proxy intercepting all web traffic, including encrypted HTTPS sessions, and introduced serious security vulnerabilities through a weak root certificate. Lenovo settled via a 20-year consent order requiring affirmative consumer consent before preinstalling software and mandating a comprehensive software security program.

## Background

Beginning in August 2014, Lenovo preinstalled ad-injecting software called VisualDiscovery on consumer laptops without meaningful disclosure. The software proxied all browser traffic — including HTTPS — collecting sensitive data such as login credentials, Social Security numbers, and financial information. It installed a self-signed root certificate with a shared, easily-cracked private key ('komodia'), exposing consumers to fraudulent certificate attacks and malware. Lenovo performed no security assessment before deployment and misrepresented the software to consumers as merely a shopping discovery tool.

## Allegations

The FTC alleged three counts: (1) deceptive failure to disclose the true nature and data-collection practices of VisualDiscovery; (2) unfair preinstallation of man-in-the-middle software that intercepted consumer internet communications without informed consent; and (3) unfair security practices, including failure to adopt written security standards, assess risks prior to preinstallation, or require the third-party developer Superfish to implement reasonable security measures.

## Outcome

Lenovo entered into a 20-year consent order (Docket C-4636, effective 2018-01-15, terminating December 20, 2037). The order prohibits misleading representations about preinstalled software, requires affirmative express consumer consent before preinstalling covered software, mandates establishment of a comprehensive written software security program, and requires biennial third-party security assessments submitted to the Commission.

## Significance

This action established that OEM preinstallation of third-party software that intercepts encrypted user communications — even when framed as a value-added feature — constitutes both a deceptive trade practice and an unfair security practice under FTC Act Section 5. It set a precedent requiring hardware manufacturers to conduct security reviews of bundled software and obtain meaningful consumer consent before deployment.
