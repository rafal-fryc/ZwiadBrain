## Summary

The FTC charged James V. Grago, Jr., operator of ClixSense.com, with deceiving 6.6 million users by falsely claiming to use 'the latest encryption and security techniques' while actually storing all personal data—including Social Security numbers and passwords—in clear text with no encryption. A 2016 data breach exposed the entire user database, with personal information of roughly 2.7 million consumers publicly posted online. The matter was resolved by a 20-year consent order requiring a comprehensive information security program and biennial third-party assessments.

## Developments

- 2019-07-15 — FTC issued 20-year consent order against ClixSense.com operator for falsely claiming encryption use while storing 6.6 million users' data in clear text, resulting in a 2016 breach exposing Social Security numbers and passwords. — [source](https://www.ftc.gov/legal-library/browse/cases-proceedings/172-3003-james-v-grago-jr-doing-business-clixsensecom-matter)

## Background

ClixSense.com collected personal information from approximately 6.6 million consumers, including names, addresses, dates of birth, Social Security numbers, and passwords. Despite public representations about using 'the latest security and encryption techniques,' the site stored all data in clear text, lacked intrusion detection, access segregation, and vulnerability testing, and allowed employees to store plain-text credentials in personal email accounts. In February 2016, an unvetted browser extension was installed directly onto the ClixSense network, providing hackers an entry point; by September 2016 the full user table had been exfiltrated and personal information of approximately 2.7 million users was publicly posted.

## Allegations

The FTC alleged three counts: (1) deceptive misrepresentation that ClixSense used the latest encryption techniques; (2) deceptive misrepresentation that it used the latest security techniques; and (3) unfair failure to employ reasonable security practices, including storing consumer data including Social Security numbers in clear text, permitting employees to keep plain-text credentials in personal email and on laptops, failing to limit network access between computers, and failing to change default login credentials for third-party network resources.

## Outcome

Grago agreed to a 20-year consent order (Docket C-4678) prohibiting misrepresentations about privacy or security of personal information, requiring establishment of a comprehensive information security program, mandating biennial third-party data security assessments by a CISSP-, CISA-, or GIAC-certified assessor, and imposing annual compliance certifications, recordkeeping for 20 years, and ongoing FTC compliance monitoring.

## Significance

The case illustrates the FTC's use of Section 5 deception and unfairness theories together against an operator who made affirmative security representations while maintaining egregiously inadequate practices, resulting in one of the more demanding consent order regimes—20 years of third-party assessments—applied to an individual respondent running a consumer-facing website.
