## Summary

The FTC charged Tapplock, Inc. with deceptively marketing its Internet-connected fingerprint padlocks as secure while failing to implement any meaningful security program. Security researchers discovered critical physical and electronic vulnerabilities in 2018, including an API flaw enabling full account takeover and unencrypted Bluetooth communications. The matter resolved as a 20-year consent order requiring Tapplock to establish a comprehensive security program and submit to biennial third-party assessments.

## Background

Tapplock, a Canadian IoT company, sold Internet-connected fingerprint-enabled padlocks to U.S. consumers under the marketing claim 'Bold. Sturdy. Secure.' and representations that it followed industry best practices to protect personal information. In June 2018, independent security researchers disclosed four critical vulnerabilities: physical back-panel removal opened the lock; an API flaw allowed full account takeover for any user; unencrypted Bluetooth enabled unauthorized locking and unlocking; and access persisted after revocation. At the time of these discoveries, Tapplock had no security program, no vulnerability testing, no authentication safeguards, no written security policies, and no employee security training.

## Allegations

The FTC alleged two counts of deceptive representation under FTC Act Section 5(a): (1) that Tapplock's smart locks were secure; and (2) that Tapplock took reasonable precautions and followed industry best practices to protect consumers' personal information. Both representations were alleged to be false given the absence of any actual security program or practices.

## Outcome

A 20-year consent order (Docket C-4718, effective May 15, 2020, terminating May 18, 2040) prohibited Tapplock from misrepresenting device or data security, required it to implement a comprehensive Security Program covering Covered Devices and Personal Information, mandated initial and biennial third-party security assessments, and imposed annual senior-officer compliance certifications, 20-year recordkeeping obligations, and FTC compliance monitoring rights.

## Significance

The case illustrates the FTC's application of Section 5 deception theory to IoT hardware security claims, holding a device manufacturer liable for advertising security properties it had never actually implemented — establishing that IoT companies must back marketing claims about security with actual technical practices.
