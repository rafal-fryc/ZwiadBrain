## Summary

The FTC charged Blackbaud, a cloud software and data services provider, with failing to implement reasonable data security practices, which allowed an attacker to access its systems undetected for over three months in 2020 and exfiltrate the sensitive personal information of millions of consumers. Blackbaud compounded the breach by issuing a false notification claiming no financial or Social Security data had been accessed. The matter was resolved through a 20-year consent order requiring comprehensive security reforms, data deletion, and ongoing FTC oversight.

## Developments

- 2024-05-15 — FTC issued 20-year consent order against Blackbaud for deficient data security practices that enabled a 2020 breach exposing millions of consumers' sensitive personal data and for issuing a materially false breach notification. — [source](https://www.ftc.gov/legal-library/browse/cases-proceedings/2023181-blackbaud-inc)

## Background

Blackbaud serves over 45,000 organizations with cloud software and data services. On February 7, 2020, an attacker gained unauthorized access to Blackbaud's databases and remained undetected for more than three months, exfiltrating unencrypted personal data including Social Security numbers, bank account information, and medical records. Security failures included weak password controls, no multifactor authentication, inadequate network segmentation, poor data retention enforcement, and unencrypted backup files. Blackbaud paid a $235,000 Bitcoin ransom but could not verify the stolen data was deleted. In July 2020, Blackbaud issued a breach notification falsely stating no financial or Social Security data had been accessed, despite knowing otherwise by July 31, 2020; accurate notification was not issued until October 2020.

## Allegations

The FTC alleged five counts: (1) unfair information security practices for failing to implement reasonable safeguards including password controls, MFA, monitoring, patch management, and network segmentation; (2) unfair data retention practices for retaining sensitive consumer data far longer than necessary, including data belonging to former and prospective customers; (3) unfair inaccurate breach notification for providing materially false information about the scope of the breach; (4) deceptive security statements in its Privacy Policy representing that appropriate safeguards protected consumers' personal information; and (5) deceptive initial breach notification falsely claiming that credit card, bank account, and Social Security data had not been accessed.

## Outcome

Blackbaud entered into a 20-year consent order (Docket C-4804) requiring it to: refrain from misrepresenting its privacy and security practices or the scope of any breach; delete customer backup files containing unnecessary personal data within 90 days; implement and maintain a comprehensive information security program meeting at least fourteen specified requirements; undergo biennial independent third-party security assessments; have its CISO certify annual compliance to the FTC; and report any covered incidents to the FTC within 10 days of notifying a government entity.

## Significance

The Blackbaud order is a significant FTC data security action targeting a B2B cloud data custodian rather than a direct-to-consumer company, establishing that intermediaries holding consumer data on behalf of clients bear independent Section 5 obligations for both security and accurate breach disclosure. The explicit count for inaccurate breach notification — alongside the deceptive notification count — signals FTC scrutiny of the content and timeliness of breach communications, not just the underlying security failures.
